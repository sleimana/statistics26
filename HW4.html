Ex. 1 · Deriving the recurrences

Observations x₁, x₂, … arrive one at a time. We want the mean and the variance after every new value, without storing the data.

Step 0 — Knuth's recurrence for the mean (the model)

k·x̄k = Σi≤k xi = (k−1)·x̄k−1 + xk
⇒ x̄k = x̄k−1 + (xk − x̄k−1) / k   — write the sum, split off the last term, recognise the previous mean

Write δk = xk − x̄k−1 (the "surprise" of the new value). Then x̄k − x̄k−1 = δk/k and xk − x̄k = δk(k−1)/k.

Step 1 — the same idea for the sum of squares SSk = Σi≤k(xi − x̄k)²

Split off the last term, and in the remaining k−1 terms re-centre on the old mean:

xi − x̄k = (xi − x̄k−1) − δk/k
SSk = Σi<k[(xi − x̄k−1) − δk/k]² + (xk − x̄k)²
   = SSk−1 − (2δk/k)·Σi<k(xi − x̄k−1) + (k−1)δk²/k² + (k−1)²δk²/k²
the middle sum is 0, because deviations from their own mean add to zero
   = SSk−1 + (k−1)δk²·(1 + k − 1)/k² = SSk−1 + ((k−1)/k)·δk²

Because (k−1)δk/k = xk − x̄k, this gives Welford's elegant form, which needs no division:

SSk = SSk−1 + (xk − x̄k−1)(xk − x̄k),   SS1 = 0

Step 2 — the variance

s²k = SSk/(k−1)  ⇒  s²k = ((k−2)/(k−1))·s²k−1 + δk²/k   (k ≥ 2)
σ̂²k = SSk/k  ⇒  σ̂²k = ((k−1)/k)·σ̂²k−1 + (k−1)δk²/k²   (population form)

Geometric reading: the increment δk·(xk − x̄k) is the area of a rectangle with sides "distance from the old mean" and "distance from the new mean". Both have the same sign, so SS never decreases.

Ex. 1 · The code

The core logic is three lines per observation, with O(1) memory and a single pass.

function welford(stream) {
  let k = 0, mean = 0, ss = 0;
  for (const x of stream) {
    k++;
    const d = x - mean;      // δₖ = xₖ − x̄ₖ₋₁       
    mean += d / k;           // x̄ₖ = x̄ₖ₋₁ + δₖ/k      
    ss += d * (x - mean);    // SSₖ = SSₖ₋₁ + δₖ(xₖ − x̄ₖ)
  }
  return { n: k, mean, ss, sampleVar: k > 1 ? ss / (k - 1) : NaN, popVar: ss / k };
}

Ex. 1 · Why bother? Numerical stability

The "textbook" one-pass formula SS = Σx² − (Σx)²/n subtracts two huge, almost equal numbers. When the data have a large offset, cancellation destroys the significant digits.

The exact sample variance does not depend on the offset (here it is the variance of the base data). The naive formula fails completely once offset² exceeds about 10¹⁶ times the variance, because double precision keeps about 16 digits. It can even return a negative variance. Welford's error grows only slowly, about linearly in the offset, and it stays usable far beyond that point. The two-pass method is also accurate, but it needs the data twice, which is impossible for a stream.

Ex. 2 · Sampling mean and variance: m hackers, n systems

Each penetration attempt gets a score in [0, 10] drawn from a fixed distribution with mean μ and variance σ². Each hacker produces n scores. For each hacker we compute x̄ and s² with Welford, then average over the m hackers.

Ex. 2 · Repeat for different n

Same distribution and m, with n = 2 … 2000. Averages stay on target. The spread across hackers shrinks like 1/√n.

What the comparisons show, and why it matters for inference

1 · Average of the sampling means ≈ μ for every n, because E[x̄] = μ (x̄ is unbiased). Individual hackers scatter around μ with standard deviation σ/√n. This is the standard error, and it is confirmed by the simulation.
2 · Average of the sampling variances ≈ σ², again for every n, even n = 2, because E[s²] = σ² when we divide by n − 1. Dividing by n (the population formula) underestimates σ² by the factor (n−1)/n, which the "SS/n" column shows clearly for small n. This is the reason for Bessel's correction: one degree of freedom is used up when x̄ estimates μ.
3 · Increasing n concentrates both statistics. Var(x̄) = σ²/n, and Var(s²) = (μ₄ − σ⁴(n−3)/(n−1))/n also shrinks like 1/n (μ₄ is the 4th central moment). One hacker with many systems is therefore enough to estimate μ and σ² precisely (consistency, the LLN of Homework 3). The distribution of x̄ becomes normal (CLT) even when the scores are skewed or discrete.
4 · Why this is useful in inferential statistics. In practice we see one sample, not m of them. Unbiasedness and the known standard error let us turn that single sample into statements about the population: point estimates (μ̂ = x̄, σ̂² = s²) and confidence intervals x̄ ± 1.96·s/√n. The simulated coverage (step 5) is close to 95% once n is moderate, and below it for tiny n, where the Student t quantile should replace 1.96. The same logic underlies tests and sample-size planning: to halve the error you need four times the systems. Welford makes all of this computable on streams (logs, IDS alerts) in one pass with O(1) memory, and without the cancellation errors of step 3.
